# Data Model — 安东尼之怒（Anthony's Wrath）

**Feature**: [spec.md](./spec.md) | **Plan**: [plan.md](./plan.md) | **Date**: 2026-10-23

本功能不引入新的数据库或持久化结构；下面的「实体」是运行期概念模型，用于约束代码结构与验收。

## 1. 自定义模式选项（CustomModeOption）

| 字段 | 说明 | 约束来源 |
| :--- | :--- | :--- |
| `optionId` | 稳定标识，形如 `<modId>:AnthonysWrathOption`；与游戏本体选项及同名第三方选项都不冲突 | FR-001、EC-007 |
| `displayName` | 双语显示名「安东尼之怒」/ `Anthony's Wrath`；界面呈现为「负面：安东尼之怒」 | FR-001、宪法二 |
| `description` | 勾选前即可见的效果说明文本（说明选择后果） | FR-014、US1 验收场景 2 |
| `selectedThisRun` | 本局是否选中的**来源说明**（存档恢复后的玩家自定义模式项列表，不做显示名匹配）；运行时以实体 4 的 `selectedOption` 为唯一状态源 | FR-002、FR-011、EC-006 |

- 关系：与「本局运行状态」一对一；选项本身不持久化额外字段。
- 校验规则：未选中 ⇒ 全程不注入（FR-011）；本 mod 未加载（卸载或禁用）时选项缺失 ⇒ 不报错（FR-001、EC-006）；选项可见性与选中状态解耦（可见 ≠ 已选）；判断一律基于 `optionId`，不得基于显示名（EC-007）。
- 生命周期：默认未选中 → 玩家勾选 → 本局生效；不提供关闭效果的开关（Out of scope）。

## 2. 诅咒牌「安东尼之怒」（AnthonysWrathCurse）

| 字段 | 说明 | 约束来源 |
| :--- | :--- | :--- |
| `cardId` | `<modId>:AnthonysWrath`，注册时确定 | FR-004 |
| `type` / `color` | `CURSE` / `CURSE` | FR-004 |
| `cost` | -2（本体「不可打出」的判定依据） | FR-005 |
| `rarity` | `SPECIAL`，与参照牌「铃铛的诅咒」一致 | FR-012、R-009 |
| `upgradeable` | `false` | FR-005 |
| `strings` | 双语名称与描述；描述按参照牌措辞直接写明「不能被打出」「不能从牌组中移除」，不使用关键词样式或颜色标记 | FR-013、宪法二 |
| `copies` | 开局注入恰好 1 张；多副本可能来自游戏内复制类效果或测试手段，一律按 FR-007 处理（实际来源以实测为准） | FR-002、FR-007 |

- 关系：属于本局牌组（Deck）的一分子；可在抽牌堆、手牌、弃牌堆、消耗堆之间移动。
- 校验规则：不可打出、不可主动消耗（FR-005）；不可从牌组移除（FR-012）；变化类效果是否作用于它，以参照牌实际结算为准（EC-003）。
- 生命周期（每个实例）：创建（开局注入）→ 在牌组中 → 洗牌后位于抽牌堆底部 → 被取得 → 触发判负（本局结束）；「被移除」这一转移在正常情况下不可达（FR-012）。

## 3. 牌组与抽牌堆（Deck / DrawPile）

- `deck`：有序卡牌集合，由开局牌组加注入牌构成。
- `drawPileOrder`：每次洗牌后确定的抽牌堆顺序。
- 不变量：
  1. 该诅咒牌存在时，每次洗牌后位于 `drawPileOrder` 的**最底部**（FR-006）。
  2. 存在多份副本时，副本在底部成组且相对顺序不变（FR-007）。
  3. 未选中该选项时，`deck` 与 `drawPileOrder` 中都不出现该牌（FR-011）。
- 状态转换：
  - 战斗开始 ⇒ 填充抽牌堆 + 首次洗牌 ⇒ **置底**。
  - 抽牌堆耗尽 ⇒ 弃牌堆洗回 + 重洗 ⇒ **置底**。
  - 卡牌 / 遗物触发洗牌（非耗尽）⇒ **置底**。
  - 抽入手中 / 效果直接取得 ⇒ 入手判定 ⇒ 判负（一次）。

## 4. 本局运行状态（RunState）

| 字段 | 说明 | 约束来源 |
| :--- | :--- | :--- |
| `selectedOption` | 本局是否选中该选项 | FR-002、FR-011 |
| `defeated` | 本局是否已因本功能终局；唯一终局标志与查询源 | FR-008、FR-009 |
| `defeatGuard` | 一次性守卫：首次判负时置位 `defeated`，保证同一局只结算一次；不是独立查询源 | FR-008、FR-010、EC-004 |

- 不变量：`selectedOption == false` ⇒ 不创建诅咒牌、不置底、不判负；`defeated == true` ⇒ 不再处理任何抽牌与玩家操作；`defeatGuard` 只承担「首次写入 `defeated`」的守卫职责。
- 不新增存档字段：本状态全部由运行时推导，`defeatGuard` 不跨存档保留（本局结束后无意义）。

## 5. 参照牌「铃铛的诅咒」（Bell's Curse，游戏本体）

- 用途：本功能在类别、稀有度、费用、文本呈现、不可移除行为与变化行为上的**对齐基准**。
- 不归本 mod 所有：不注册、不修改、不复制其资源文件；实现期只读取其实测行为与文本措辞。
- 约束：本 mod 不得增加参照牌没有的限制，也不得放宽参照牌已有的限制（FR-012、EC-003、EC-011）。
