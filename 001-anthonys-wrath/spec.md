# Feature: 安东尼之怒 (Anthony's Wrath)

## Problem

自定义模式（Custom Mode）的负面选项目前全部来自游戏本体，选择它们只是改变开局条件，玩家仍然可以通过技术或构筑把负面影响消化掉。缺少一个**无法通过操作化解、只能被推迟**的负面选项：一旦选择，整局都背着一颗定时炸弹，牌组资源被持续压缩。

本功能为自定义模式增加这样一个负面选项。

## Goals

- 在自定义模式的选项列表中增加一个负面选项「安东尼之怒」。
- 选项生效时，在开局牌组中加入一张同名诅咒牌「安东尼之怒」。
- 该诅咒牌在每次洗牌后必定位于抽牌堆最底部，构成对玩家的可预期压力。
- 玩家抽到该诅咒牌时，本局立即判负。

## User Stories

- US-001：作为自定义模式玩家，我在选项列表中选择「安东尼之怒」并开始新的一局，进入游戏后我的牌组中多出一张名为「安东尼之怒」的诅咒牌，我可以在牌组查看界面中看到它。
- US-002：作为玩家，每当我经历一次洗牌（无论是战斗开始还是抽牌堆耗尽后的重洗），我都能确认「安东尼之怒」位于抽牌堆的最底部，因此它在本次洗牌后不会被立刻抽到。
- US-003：作为玩家，随着战斗推进，「安东尼之怒」最终会被抽入手中；在这一刻我立即输掉本局，不需要等到回合结束或生命值归零。
- US-004：作为玩家，即使我没有选择该选项，我的游戏体验也不受任何影响：选项不出现、牌组中不会多出任何牌。
- US-005：作为玩家，我无法通过任何"移除卡牌"的途径把它从牌组中除去（商店移除服务、休息点移除、以及各类移除卡牌的事件），牌面会像参照牌「铃铛的诅咒」那样直接写明它无法从牌组中移除。

## Functional Requirements

- FR-001：自定义模式选项列表中必须出现一个由本 mod 提供的负面选项，其标识独立于游戏本体选项；当 mod 被卸载后，该选项不得再出现。
- FR-002：当该选项被选中并开始新的一局时，开局牌组中必须加入**恰好一张**「安东尼之怒」诅咒牌。
- FR-003：该诅咒牌必须在开局牌组初始化完成后、第一次洗牌发生之前就已存在于牌组中（含开局牌组为空的自定义开局）。
- FR-004：该诅咒牌必须被游戏识别为「诅咒」类别，从而与游戏本体对诅咒的既有处理保持一致。
- FR-005：该诅咒牌不可被打出，也不可在战斗中被主动消耗。
- FR-006：在每次洗牌结束、洗牌后牌堆顺序已确定的时刻，该诅咒牌必须位于抽牌堆的最底部位置。
- FR-007：当该诅咒牌存在多张时，全部副本必须成组置于抽牌堆底部，且副本之间的相对顺序不发生改变。
- FR-008：当该诅咒牌被抽入手中时，本局必须立即以失败结束；结束判定发生在抽牌动作完成时，不延迟到回合结束或后续结算，且此后本局不再处理任何后续抽牌或玩家操作。
- FR-009：因抽到该诅咒牌而结束时，游戏必须展示玩家可见的失败结算（即玩家能明确知道本局因抽到该牌而失败），且该局在游戏记录中计为失败。
- FR-010：抽到该诅咒牌触发的失败只发生一次；即使同一时刻有多张副本被抽入手中，也只结算一次失败。
- FR-011：玩家未选择该选项时，本功能不得向牌组、抽牌堆或任何战斗流程注入该诅咒牌。
- FR-012：该诅咒牌必须与游戏本体的参照牌「铃铛的诅咒」拥有相同的不可移除行为：玩家无法把它从牌组中除去。此性质在游戏内的呈现不使用任何关键词样式，而是以牌面描述文本直接写明（与参照牌一致）。本 mod 不增加参照牌所没有的限制，也不放宽参照牌已有的限制。
- FR-013：该诅咒牌的描述文本必须与参照牌「铃铛的诅咒」的呈现方式一致：直接写明它无法从牌组中移除，不使用任何关键词样式或颜色标记。中英双语齐全，措辞与游戏内既有用词保持一致。

## Success Criteria

- SC-001：选择该选项并进入第一场战斗，检查抽牌堆可见顺序，可观察到「安东尼之怒」位于抽牌堆最底部。
- SC-002：在一场战斗中触发至少两次抽牌堆重洗（例如通过抽空牌组），每次重洗后检查抽牌堆，均可观察到「安东尼之怒」仍位于最底部。
- SC-003：当「安东尼之怒」被抽入手中时，本局在**同一瞬间**结束（无需玩家再执行任何操作），且结算界面显示本局失败。
- SC-004：不选择该选项开始一局，其牌组内容与未安装本 mod 时逐张一致。
- SC-005：完成一次完整验证无需阅读代码：仅凭游戏内界面与操作即可判断以上四项是否成立。

## Edge Cases

- EC-001：同一场战斗中发生多次洗牌（战斗开始、抽牌堆耗尽、以及任何由卡牌或遗物触发的洗牌），每一次都必须把该诅咒牌放到抽牌堆底部。
- EC-002：战斗开始时牌组为空（自定义模式允许空开局牌组）的情况下，仍必须先把该诅咒牌加入牌组，再执行第一次洗牌。
- EC-003：该诅咒牌如何被"变化"类效果对待，以参照牌「铃铛的诅咒」的实际结算为准，本 mod 不自行规定。若参照牌可被变化，则本牌同样可被变化，且一旦被变化，该牌在本局余下的所有战斗中都不再存在（变化作用于玩家牌组本身，是永久的）。无论哪种情形，置底与抽到即负两条规则都只在该牌存在于牌组时适用，牌不在时相应逻辑直接跳过，不产生额外判定。
- EC-004：抽到该诅咒牌时，若手中或场上存在其他待结算效果，失败判定在抽牌动作完成后立即进行，过后不再产生可操作的结果。
- EC-005：玩家主动放弃本局（放弃战斗或退出）时，不触发本功能特有的失败判定，按游戏原有流程处理。
- EC-006：mod 被卸载后重新加载一个曾选择过该选项的旧存档，必须不因该选项缺失而崩溃（与宪法第四条「存档兼容」一致）。
- EC-007：若其他 mod 提供了显示名称相同的选项，两者必须能通过各自的标识区分，不得互相覆盖或消失。本项为设计约束，不单独安排验收手段（依赖第三方 mod 才可复现），选项标识不与游戏本体选项冲突由注册环节覆盖。
- EC-008：该诅咒牌若被「搜寻」类效果从抽牌堆或弃牌堆直接取入手中（不经过抽牌动作），同样判定为失败。
- EC-009：在商店移除服务、休息点移除或移除卡牌的事件中，若该牌应当被列为候选目标，则它必须不出现或被拒绝；在这类界面中成功移除该牌的情况一律视为违规。
- EC-010：本体在每次开局与读档时重建随机诅咒池，卡牌库中所有「诅咒」类别的牌都会被纳入（参照牌等四张由本体硬编码排除）。本牌必须不在该池内：未选择该选项时，任何随机诅咒来源（事件、遗物）都不得发出本牌，标准模式与每日挑战同样不得出现（与「不选择时不得注入」一条及「Out of Scope」一致）。
- EC-011：本体允许在持有「蓝蜡烛」时打出费用低于 -1 的诅咒牌（消耗 1 点生命并在战斗中消耗掉），也允许「恶魔之焰」一类效果消耗手牌中的牌；本牌与参照牌一样受这些既有规则影响，不额外增加限制。由于本牌进入手牌即判负，任何需要它停留在手牌中的操作（打出、消耗）在实际游戏中都不可达，「不可打出、不可被主动消耗」由此成立。

## Out of Scope

- 不新增角色、遗物、药水或其它卡牌。
- 不修改任何原版卡牌、遗物或事件的数值与行为，也不改变它们对其它卡牌的既有处理（本功能不改动原版内容本身；为对齐参照牌的"不可移除"与"不被随机诅咒来源发出"，需要拦截原版判定点，但拦截只针对本牌，落点见 plan）。
- 不为标准模式、每日挑战（Daily Climb）或自定义模式中的其它选项增加该诅咒牌。
- 不提供关闭该诅咒牌效果的开关（当前阶段不引入内容总开关）。
- 不设计新的美术资源以外的表现优化（例如专门的抽牌动画或特效）。

## Assumptions

- 该诅咒牌在自定义模式中的加入时机对齐游戏本体的「开局获得诅咒」类负面选项：在牌组初始化阶段加入，早于第一次洗牌。
- 「洗牌」指对抽牌堆的重洗动作（战斗开始时的初始化洗牌，以及抽牌堆耗尽后的重洗），不包含非战斗场景中的牌组操作。
- 该诅咒牌不可打出、不可消耗；它无法被任何"移除卡牌"的来源移出牌组，但"变化"类效果仍可把它变成别的牌。
- 该诅咒牌在结算失败时，走游戏本体的失败流程，因此与生命值归零的失败在记录层面表现一致。
- 英文名称定为 `Anthony's Wrath`（对应中文「安东尼之怒」），以满足宪法第二条的中英双语要求。
- 选项在界面上的显示为「负面：安东尼之怒」，即在名称前带负面标记，与游戏本体负面选项的呈现方式一致；该前缀由界面槽位提供还是需写入选项文本，在实现阶段比对游戏内文本后确定，以避免出现重复前缀。
- 失败时机的表现：先完成抽牌动作、让玩家看到该牌进入手中，随后立即进行失败判定；不要求在抽牌动画结束前中断画面。
- 「取得该牌」的判定范围：无论经由抽牌动作还是被效果直接从抽牌堆、弃牌堆取入手中，均视为取得并触发失败。
- 「每场战斗都重新置底」：只要该牌仍在牌组中，每场战斗开始时它都会重新位于抽牌堆底部；上一场战斗未抽到它，不会使其在下一场战斗中失去置底行为。（该牌被移除或变化后不再存在于牌组，本句自然不适用。）
- 「不可移除」的含义与结算完全对齐参照牌「铃铛的诅咒」：不加限制、不放宽。杀戮尖塔 1 中不存在"永恒"词条，参照牌的不可移除性质以牌面描述文本直接写明（"无法从牌组中移除"），本 mod 照此呈现，不实现任何关键词机制。该牌是否可被"变化"类效果处理，同样以参照牌的实际行为为准，不在此处断言。

## Open Questions

- 失败时机、非抽牌取得是否判负、英文名称与描述写法这三项已在需求澄清中确认，结论写在「Edge Cases」与「Assumptions」中，不再作为待定项。
- [NON-BLOCKING] OQ-005：该选项在自定义模式界面中是否必须显示效果说明文本（选择前告知玩家后果），还是仅显示名称？当前写法只要求选项本身出现，未强制要求说明文本。
